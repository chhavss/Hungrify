# 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/chhavss/Hungrify.git
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

Build production

```bash
npm run build
```

Preview production

```bash
npm run preview
```
